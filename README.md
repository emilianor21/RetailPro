# README

Para el desarrollo de esta entrega se realizaron algunas adaptaciones sobre la base de datos utilizada en módulos anteriores, con el fin de cumplir los requerimientos de la consigna y contar con información suficiente para el análisis.

Se incorporaron algunos campos y registros adicionales para enriquecer el modelo de datos y facilitar la resolución de las consultas solicitadas. A partir de estas modificaciones se implementaron consultas utilizando `INNER JOIN`, `LEFT JOIN`, `UNION ALL` y funciones de agregación para responder distintos escenarios de negocio.

El proyecto fue desarrollado en **SQL Server Management Studio (SSMS)** y está pensado como base para su posterior utilización en **Power BI**.
